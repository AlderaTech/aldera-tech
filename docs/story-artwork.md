# Ilustrasi Cerita Aldera Tech

- Aset: [aldera-story-workflow.webp](../public/images/about/aldera-story-workflow.webp).
- Penempatan: bagian Dari frustasi, lahirlah solusi. pada halaman Tentang melalui `app/(public)/about/_components/about-story-visual.tsx` dan stylesheet lokal `about-story.module.css`.
- Konsep: fragmen pekerjaan yang tersambung ke dashboard terstruktur, milestone, komunikasi, dan dokumen. Ilustrasi mengikuti tema transparansi pada cerita perusahaan dan palet putih, navy, biru elektrik, serta kaca biru muda.
- Aset merupakan ilustrasi konseptual, bukan foto studio atau screenshot produk nyata. Gambar tidak berisi teks, angka, nominal invoice, atau statistik bisnis. Ketiga paragraf cerita asli tetap dirender sebagai HTML melalui `AboutStoryStep`.
- Format: WebP transparan 768×768, 82.720 byte, kualitas 90 dan alpha kualitas 100. Sumber generasi disimpan oleh tool; aplikasi memakai salinan portabel di dalam proyek.
- Aset `public/images/about/about-studio.webp` tetap tersedia untuk kompatibilitas URL gambar publik. Komponen cerita menggunakan `aldera-story-workflow.webp` sebagai ilustrasi aktif.
- Pembuatan: tool bawaan `imagegen`, melalui satu prompt generasi baru. Konversi dan kompresi menggunakan Sharp.
- Rendering: `next/image`, static import, lazy loading, kualitas 90, dan `sizes` responsif. Ilustrasi serta penanda ringkasnya bersifat dekoratif (`aria-hidden`, `alt=""`) karena maknanya sudah tersedia dalam cerita.
- Animasi: float ringan hanya aktif jika reduced motion tidak diaktifkan. Orbit, latar, serta bayangan memakai CSS.
