# Aldera Tech — UI Design & Artwork Documentation

Dokumen ini merupakan indeks dan repositori dokumentasi estetika, spesifikasi desain antarmuka pengguna (UI specifications), dan catatan perancangan aset ilustrasi/maskot 3D untuk **Aldera Tech**.

---

## 1. Tujuan Direktori `design-docs/`

Direktori ini dipisahkan dari [`ai-agent-docs/`](../ai-agent-docs/README.md) agar:

- Tim desain grafis, ilustrator, dan UI/UX memiliki arsip referensi konsep visual, tata letak, dan prompt aset.
- AI coding agent dapat fokus pada dokumen protokol teknis di `ai-agent-docs/` tanpa terbebani artefak teks presentasional yang panjang.
